# ryanspletzer/ryanspletzer

GitHub profile README repository.
The `README.md` in this repo renders on
[github.com/ryanspletzer](https://github.com/ryanspletzer).

## Purpose

This is a special GitHub repository whose sole purpose is to display
a profile README on Ryan Spletzer's GitHub profile page.
It contains only a `README.md` (and this file).

## Constraints

- **GitHub Markdown only** — the README renders on github.com,
  so only GitHub Flavored Markdown features are supported
  (no custom CSS, no JavaScript, no external iframes)
- **Images** must be hosted externally or committed to the repo
  and referenced via raw URLs
- GitHub profile READMEs support HTML subset:
  `<img>`, `<a>`, `<details>`, `<summary>`, `<picture>`, `<source>`,
  `<p>`, `<div>`, `<table>`, `<tr>`, `<td>`, `<th>`, alignment attributes
- SVG badges and shields.io URLs work well for dynamic content
- Keep the README concise — it's a profile introduction, not a resume
- Emojis are welcome here (profile READMEs are casual by convention)
